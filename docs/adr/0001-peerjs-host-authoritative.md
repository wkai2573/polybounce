# 使用 PeerJS 點對點連線，由房主擔任權威

線上多人以 PeerJS 的點對點連線實作，不架設獨立的遊戲伺服器。房主的瀏覽器獨自執行完整的物理運算，包含彈珠、碰撞、怪物與子彈；其他玩家只傳送輸入並接收狀態。單人模式沿用同一套房主邏輯，只是沒有任何連線。

## Considered Options

- 各端各自運算再互相同步：被否決，彈珠高速碰撞下各端結果很容易分歧，且難以除錯。
- 獨立的權威伺服器：被否決，需要維運成本，與目前免伺服器的網頁遊戲目標不符。

## Consequences

- 房主離線，整局結束。
- 房主以外的玩家會感受到網路延遲，輸入回饋比房主慢。
- 因為單人與房主共用同一套邏輯，遊戲核心必須與網路層分離。
