# Polybounce

多人合作的彈珠打磚塊遊戲：玩家各佔方形場地的一邊，用擋板接住彈珠，擊碎場地中央的磚塊與怪物。單人可以直接在瀏覽器遊玩，多人用房間碼點對點連線，不需要伺服器。

線上遊玩：https://wkai2573.github.io/polybounce/

## 玩法

- 場地四邊各是一個方位，沒有玩家的方位會變成牆。一個人玩時自己在下方，其餘三邊是牆。
- 玩家用擋板接住彈珠並彈回場地，擊碎磚塊與怪物即過關。
- 每顆彈珠有攻擊力：新發射為一，被任何玩家的擋板彈回一次加一（撞牆、磚塊、怪物都不算），沒有上限；打到磚塊與怪物時扣的血量等於攻擊力。攻擊力越高彈珠越大、顏色從白色漸變到金黃再到亮紫：半徑每多一點攻擊力多 12%，到兩倍為止。
- 彈珠是無限的，但每位玩家有自己的發射量：最大五顆，每秒恢復一顆，左鍵發射一次消耗一顆，不足一顆時按了沒有作用。擋板就是發射條：等分五格，滿的格子填色，正在恢復的那格慢慢填滿，沒有彈珠時擋板是中空的，隊友的擋板也看得到。開局、每過一關與接關時所有人補滿，死亡時凍結。
- 第 3 關起中央會出現紫色的怪物：第 3 關起兩隻，之後每三關多一隻，上限四隻，與玩家人數無關。每隻怪物各自計時，朝隨機一位活著的玩家的核心發射子彈；發射間隔從 3 秒起，每過 5 關縮短 0.5 秒，最短 1.5 秒。子彈不會被磚塊擋住，半徑 8。
- 每 5 關是 BOSS 關，只有一隻深紅色的 BOSS。BOSS 輪流施放環形、瞄準扇形與螺旋三種彈幕，血量降到一半以下會狂暴。BOSS 的子彈半徑 6，比一般怪物的小；所有敵方子彈同為紅色，橘色只留給貫通。
- 每位玩家有自己的生命，初始 3 點。擋板中央有一個小方塊「核心」，子彈穿過擋板本身，只有打到核心才扣 1 點生命並消失，不分一般怪物或 BOSS。受傷或復活後有 1.5 秒無敵，期間核心閃爍，子彈穿過核心。生命以核心內側的小圓點顯示。
- 生命歸零的玩家死亡：擋板停在原地變成灰色半透明的屍體，該方位整條變成牆，不能移動或發射。活著的隊友用彈珠撞屍體，累計 5 次就能把他救回來（回來時 1 點生命與 1.5 秒無敵）。每過一關，死亡的玩家一起復活，所有人生命補滿。
- 全部玩家都死亡，全隊失敗。
- 磚塊被擊碎時有機率掉落道具，需要用擋板碰到才能拾取。死亡玩家的方位不會掉落。所有機率與權重集中在 [drop-config.ts](src/core/drop-config.ts)：
  - 多球：場上每顆彈珠各分裂為三顆，最常出現。
  - 加寬：擋板變寬一段時間。
  - 貫通：整場效果，3 秒內所有彈珠（含新發射與分裂出的）穿過磚塊與怪物，沿途每次扣的血量等於彈珠的攻擊力，仍被牆與擋板反彈。
  - 環爆：稀有，場上每顆彈珠原地分裂成 10 顆，向四周散開。
  - 補血：自己的生命加 1 點，不超過 3 點，各接各的；不能復活屍體。
  - 縮短擋板（nerf）：只有自己的擋板縮短為 0.6 倍、6 秒，與加寬互相覆蓋。
  - nerf 機率較小（約佔磚塊掉落的 5%），且不會從怪物血量門檻必掉。
- 整場效果是全隊共用的一份倒數；全隊共用的道具同一批只有第一個被接到的生效。所有效果的剩餘時間都顯示在場地右側的效果面板（見下）。
- 房間最多 4 人，開局後不能中途加入。玩家中途離線，他的方位變成沒有屍體的牆。

## 效果面板

場地旁邊有一欄寬約 200 像素的效果面板，寬螢幕在場地右側，窄螢幕或直向時移到場地下方。它只顯示正在生效的效果，每一列有名稱、依道具顏色的倒數條與一位小數的剩餘秒數；沒有效果的區整區留空：

- **全隊**：貫通。
- **玩家**：依座位順序列出每位玩家的加寬或縮短。列首的圓點是該玩家方位的顏色，自己那一列加亮，死亡玩家的列灰色顯示、時間不倒數。

## 選關與接關

- 單人在主選單、多人由房主在大廳選擇起始關卡（1 到 99），預設第 1 關。
- 失敗後房主可以「從第 N 關接關」（N 是失敗的那一關）：分數歸零、發射量補滿、關卡配置換新；也可以「再來一局」回到這一局的起始關卡。其他玩家只能等房主按。
- 最高紀錄只計從第 1 關開始的局；從第 1 關開始後接關的局仍然算同一局，所以接關後打到更高的關卡，紀錄照樣更新。

## 操作

| 操作 | 說明 |
| --- | --- |
| 滑鼠移動 | 畫面會把你的方位旋轉到下方，所以滑鼠左右移動時擋板沿畫面左右移動、上下移動時沿畫面上下移動（旋轉不是鏡像）。沿自己的方位移動擋板，畫面上的準星標示指標位置。滑鼠的另一軸控制擋板往場地內側移動，指標離自己那一邊越遠，擋板越往內，最多 100 像素，停在哪就留在哪。遊戲開始與接關時指標從自己那一邊的邊緣開始 |
| 點一下畫面 | 對局中鎖定滑鼠；這一下點擊只用來鎖定，不會發射 |
| 左鍵 | 按一下從擋板垂直射出一顆彈珠，按住不會連發；右鍵沒有作用 |
| `Esc` | 解除滑鼠鎖定。房主與單人同時暫停，再點一下畫面就重新鎖定並繼續；其他玩家只是回到「點一下重新鎖定」 |
| `P` | 暫停或繼續，只有房主與單人可用 |
| `M` | 切換靜音 |

擋板往內移動時，核心、彈珠反彈的表面、道具拾取範圍與發射起點都跟著走；彈珠漏接、子彈消失與道具消失仍以原本的邊緣為準，所以死亡玩家的屍體可能漂在離牆最多 100 像素的地方。

擋板任何時候都能移動，發射前後都不會被鎖住。主選單、大廳、暫停與結算畫面不鎖定滑鼠。瀏覽器不支援或拒絕滑鼠鎖定時，會退回一般的滑鼠行為，此時 `Esc` 直接切換暫停。

## 本機開發

需要 [Bun](https://bun.sh)。

```sh
bun install
bun run dev        # 開發伺服器
bun run build      # 建置到 dist
bun run typecheck  # 型別檢查
bun test           # 執行測試
```

## 版本號

主畫面右下角顯示版本號，格式為 `v主版本.次版本.修訂號`。主版本與次版本寫在 [package.json](package.json) 的 `version`，修訂號是建置時 git 的 commit 總數，所以每次 commit 都會自動遞增，不必手動改。要升主版本或次版本時才修改 package.json。游標移到版本號上可以看到對應的 commit。

## 部署

推送到 `main` 後，[GitHub Actions](.github/workflows/deploy.yml) 會依序跑型別檢查、測試與建置，通過後自動部署到 GitHub Pages。

```

  net/      PeerJS 房間與連線，房主權威

  audio/    合成音效
```
