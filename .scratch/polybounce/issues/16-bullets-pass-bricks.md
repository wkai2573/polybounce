# 16：所有怪物的子彈穿過磚塊

**要建置什麼：** 怪物與 BOSS 發射的子彈不再被磚塊擋住，玩家不能躲在磚塊後面。子彈仍然在碰到牆、越過有玩家的那一邊或打到擋板時消失。同時讓每發子彈記錄自己的來源種類（BOSS 或一般怪物），這個欄位會隨狀態同步到連線玩家端，供後面的票券決定半徑、顏色與凍結規則。一般怪物的發射頻率與目標都不變。來源：規格 0002。

**Blocked by（被誰阻擋）：** 無（可立即開始）

**Status：** ready-for-agent

- [ ] 子彈飛過磚塊所在的位置時不會消失，也不會損傷磚塊
- [ ] 子彈碰到牆、越過有玩家的那一邊、打到擋板時仍然消失；打到擋板仍然凍結玩家一秒
- [ ] 一般怪物維持每 5 秒向隨機一位玩家發射一發
- [ ] 每發子彈帶有來源種類，BOSS 發射的標為 BOSS，其他標為一般怪物；現階段兩者的外觀與行為相同
- [ ] 來源種類包含在同步給連線玩家端的狀態中
- [ ] 詞彙表更新「子彈」的說明：不再被磚塊擋住
- [ ] 遊戲核心的新行為都有測試；原本「子彈打到磚塊就消失」的測試改成新的行為，其餘現有測試維持通過
