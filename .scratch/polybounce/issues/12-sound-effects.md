# 12：合成音效

**要建置什麼：** 用瀏覽器內建的 Web Audio 合成音效，不需要任何音檔。涵蓋撞磚、發射、接到道具、凍結、過關與失敗這些事件。等這些事件都已存在才做，所以排在怪物、子彈與道具之後。

**Blocked by（被誰阻擋）：** 03：怪物發射子彈與凍結；07：多球道具與場上彈珠上限

**Status：** ready-for-agent

- [ ] 撞磚、發射、接到道具、凍結、過關與失敗各有一個可以分辨的音效
- [ ] 音效全部由 Web Audio 合成，專案內沒有新增音檔
- [ ] 多球造成大量彈珠同時撞擊時，音效不會爆音或卡頓
- [ ] 遵守瀏覽器的自動播放限制：使用者第一次操作後才開始發聲
- [ ] 音效有靜音的開關
- [ ] 音效不屬於核心測試的範圍，在真實瀏覽器確認過
