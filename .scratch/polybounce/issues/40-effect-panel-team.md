# 40：右側效果面板，版面與全隊區

**要建置什麼：** 場地旁新增一欄獨立的效果面板，寬度固定約兩百像素，寬螢幕時在場地右側，窄螢幕或直向時移到場地下方，場地的縮放要考慮面板所佔的空間。面板內容由一個純函式從遊戲狀態與本機玩家的方位推導。本張先做「全隊」區：顯示貫通與彈珠大小，每一列有名稱、依道具顏色的倒數條與一位小數的剩餘秒數；沒有任何生效的效果時整區留空，連標題也不顯示。場地上方中央原本的整場效果標籤移除，上方的關卡、分數與彈珠池資訊不動。面板只讀取狀態，不增加任何同步的資料量。來源：規格 0004。

**Blocked by（被誰阻擋）：** 無（可立即開始）

**Status：** ready-for-agent

- [ ] 面板推導函式輸入遊戲狀態與本機方位，輸出全隊區的各列：標籤、顏色、剩餘比例、剩餘秒數
- [ ] 貫通、放大彈珠、縮小彈珠各自對應正確的名稱與道具顏色；彈珠大小只會有放大或縮小其中一個
- [ ] 剩餘秒數取一位小數，倒數條比例等於剩餘比總時長
- [ ] 沒有任何整場效果時全隊區不輸出，面板留空
- [ ] 面板在寬螢幕出現在場地右側，窄螢幕或直向時移到場地下方；場地不會被面板擠出螢幕
- [ ] 場地上方中央的整場效果標籤移除，上方資訊列不動
- [ ] 面板每個畫面更新一次，只讀取目前狀態；玩家端與房主看到相同的內容
- [ ] 測試涵蓋：推導函式的全隊區內容與順序、只列出生效中的效果、沒效果時不輸出、剩餘秒數與比例
- [ ] 詞彙表新增「效果面板」
- [ ] 手動驗證：面板的外觀、響應式版面、場地縮放只能在瀏覽器中目視確認，不屬於自動化測試範圍
