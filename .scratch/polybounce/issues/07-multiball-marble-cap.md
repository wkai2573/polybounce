# 07：多球道具與場上彈珠上限

**要建置什麼：** 新增第三種道具：多球。被接到時，場上所有彈珠各分裂為三顆，包含其他玩家發射的。這是全隊共用的效果，同一批只有第一個被接到的生效。分裂出來的彈珠不計入彈珠池。同時加入場上彈珠數量上限，避免多球讓遊戲卡頓。

**Blocked by（被誰阻擋）：** 05：道具掉落與補給

**Status：** done

- [x] 道具的掉落類型包含多球，同一批掉落的所有道具仍然是同一種類型
- [x] 多球被接到時，場上每顆彈珠各分裂成三顆，速度大小不變、方向略有不同
- [x] 分裂出來的彈珠不會從彈珠池扣除，也不會增加彈珠池
- [x] 同一批多球只有第一個被接到的生效，其餘立刻消失
- [x] 場上彈珠數量有上限，預設約 100 顆，超出的分裂結果不產生；上限寫成可調整的常數
- [x] 失敗條件仍然只看「彈珠池為空且場上沒有任何彈珠」，不受分裂影響

- [x] 在真實瀏覽器確認多球時畫面與效能仍然流暢
