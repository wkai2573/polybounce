# 21：大廳選關與連線同步

**要建置什麼：** 多人房間裡，房主在大廳選擇起始關卡，其他玩家在大廳看得到房主選的關卡。開局後所有人都從該關卡開始，起始關卡與這一局的起點旗標也同步到玩家端。非房主的玩家不能更改。來源：規格 0002。

**Blocked by（被誰阻擋）：** 20：起始關卡：單人選關與再來一局回起點

**Status：** ready-for-agent

- [ ] 房主在大廳可以調整起始關卡（1 到 99），預設 1
- [ ] 大廳訊息把目前的起始關卡傳給所有玩家，玩家加入時就看得到，房主調整時即時更新
- [ ] 非房主的玩家在大廳只能看到起始關卡，不能更改
- [ ] 房主按開始後，全隊從所選關卡開始，彈珠池依當時的玩家人數補滿
- [ ] 玩家端收到的遊戲狀態包含起始關卡，與房主一致
- [ ] 玩家離開或加入大廳時，起始關卡設定不會被重設
- [ ] 以記憶體內的假連線測試：房主調整後玩家端看到相同的值，開局後雙方狀態一致；現有測試維持通過
