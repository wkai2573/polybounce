# 38：擋板可往內移動

**要建置什麼：** 玩家的擋板除了沿自己那一邊滑動，還能垂直於那一邊往場地內側移動最多一百像素，四個方位對稱。擋板深度由滑鼠指標離自己那一邊的距離決定，夾在零到一百，停在哪就留在哪。瞄準模式下沿邊位置與深度都鎖住；死亡時停在原位，復活後留在原位，下一個輸入再接手。擋板往內追上正往邊緣飛的彈珠時要能反彈；往外退時板後的彈珠不被困住，飛出原本的邊緣仍算漏接。擋板、核心、生命圓點、無敵閃爍都隨深度顯示。遊戲開始與接關時，前端把指標放在自己那一邊的邊緣。玩家端看到的深度與房主一致。來源：規格 0004。

**Blocked by（被誰阻擋）：** 37：預先重構，擋板深度欄位先接上

**Status：** ready-for-agent

- [ ] 擋板深度等於指標離自己那一邊的距離，夾在零到一百；上下左右四個方位都成立
- [ ] 指標超出範圍時深度停在上限或零，不會往外超出場地或進入更深處
- [ ] 瞄準模式下沿邊位置與深度都不更新；取消或發射後恢復跟隨指標
- [ ] 死亡玩家不再接收輸入，擋板停在死亡時的位置與深度；復活後留在原位，下一個輸入再接手
- [ ] 彈珠在擋板目前的表面反彈；擋板往內移動追上往邊緣飛的彈珠時會反彈它
- [ ] 擋板往外退時，板後的彈珠不被困住，繼續飛出邊緣並算漏接；漏接判定仍在原本的邊緣
- [ ] 彈珠從擋板目前的位置發射
- [ ] 核心、生命圓點、復活進度、無敵閃爍隨深度顯示在正確位置
- [ ] 前端在遊戲開始與接關時把指標放在自己那一邊的邊緣，擋板不會一開局就頂在最深處
- [ ] 連線：玩家端收到的其他玩家深度與房主一致，數字壓縮後仍正確
- [ ] 深度上限寫成常數
- [ ] 測試涵蓋：深度換算與夾限、四個方位對稱、瞄準鎖定、死亡與復活的深度、追球反彈、退讓不困球、漏接仍在邊緣、發射起點、玩家端與房主一致
