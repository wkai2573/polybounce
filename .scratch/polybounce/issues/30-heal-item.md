# 30：補血道具

**要建置什麼：** 新增補血道具，個人效果、各接各的。活著的玩家接到時自己的生命加 1，最多到 3 點，不能復活屍體。道具有自己的顏色與標籤，權重 8，加進機率設定檔，沿用現有的拾取音。補血也可以出現在怪物血量門檻的必掉。來源：規格 0003。

**Blocked by（被誰阻擋）：** 25：機率設定檔集中、27：生命與核心受擊

**Status：** ready-for-agent

- [ ] 補血進入道具種類，並出現在磚塊掉落與怪物必掉；權重 8，寫在機率設定檔
- [ ] 活著的玩家接到補血時自己的生命加 1，不超過 3 點；生命已滿時接到也不增加
- [ ] 補血各接各的，不影響其他玩家，不需要批次規則
- [ ] 補血不能復活屍體，死亡玩家的方位本來就不掉落道具
- [ ] 道具有專屬顏色與標籤，沿用現有的拾取音效
- [ ] 連線：玩家端看到的補血道具與生命與房主一致
- [ ] 測試涵蓋：補血加 1、上限、各接各的、不復活、權重在抽選範圍內
- [ ] 詞彙表新增「補血」並更新「道具」；README 補上補血說明
