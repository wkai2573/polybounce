# 14：貫通道具

**要建置什麼：** 新增「貫通」道具。玩家接到時，場上目前所有的彈珠各自獲得 6 秒的貫通：穿過磚塊與怪物而不反彈，沿途扣血，但仍然被牆與擋板反彈。只有接到那一刻已在場上的彈珠獲得，之後才發射的不算。貫通是全隊共用的效果。貫通中的彈珠以不同顏色並帶光暈顯示，道具本身有新的顏色與標籤。來源：規格 0002。

**Blocked by（被誰阻擋）：** 13：掉落率與權重制

**Status：** ready-for-agent

- [ ] 貫通加入道具種類，權重為 15
- [ ] 接到貫通時，場上所有彈珠的貫通剩餘秒數設為 6；之後才發射的彈珠沒有貫通
- [ ] 貫通中的彈珠穿過磚塊，每塊磚扣 1 血，硬磚不會被一下打碎，磚塊碎裂時照常得分與機率掉落
- [ ] 貫通中的彈珠穿過怪物與 BOSS，每次進入扣 1 血；留在怪物內部不會每個小步長都扣血，離開後再進入才再扣一次
- [ ] 貫通中的彈珠仍然被牆與擋板反彈
- [ ] 倒數歸零後，彈珠恢復碰到磚塊與怪物就反彈
- [ ] 再接到貫通時重新計時，不疊加
- [ ] 同一批貫通只有第一個被接到的生效，其他玩家方位的同批道具消失
- [ ] 多球分裂出的彈珠繼承原彈珠的貫通剩餘時間
- [ ] 貫通剩餘時間隨狀態同步到連線玩家端，玩家端看得到光暈
- [ ] 拾取音效沿用現有的道具拾取音效
- [ ] 詞彙表新增「貫通」，道具清單同步更新
- [ ] 遊戲核心的新行為都有測試，現有測試維持通過
