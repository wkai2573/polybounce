# 48：攻擊力決定半徑與顏色

**要建置什麼：** 彈珠的半徑隨攻擊力線性成長：基礎半徑乘以一加零點一二乘以攻擊力減一，倍數上限為二。依這個公式攻擊力九是 1.96 倍，十以上才固定為兩倍；規格寫的「九達到兩倍」與公式差一點，實作照公式。碰撞、漏接判定與畫出來的半徑一致。顏色從白色漸變到金黃再到亮紫，不畫數字；貫通期間仍為橘色並帶光暈。玩家一眼就能從大小與顏色看出一顆彈珠現在多強。來源：規格 0005。

**Blocked by（被誰阻擋）：** 46：攻擊力累積與扣血；47：移除放大與縮小

**Status：** 待手動驗證

- [x] 每顆彈珠的半徑由它自己的攻擊力決定；係數與倍數上限寫成常數
- [x] 攻擊力一為基礎半徑，成長為線性，攻擊力十以上固定為兩倍
- [x] 牆、擋板、磚塊、怪物的碰撞、漏接判定、切段步長都使用該顆彈珠自己的半徑；大彈珠被擋板彈回時不穿過也不卡進去
- [x] 場上不同攻擊力的彈珠半徑各自獨立
- [x] 彈珠顏色依攻擊力在白、金黃、亮紫之間漸變，攻擊力九以上固定為亮紫，不畫數字
- [x] 貫通期間彈珠仍為橘色並帶光暈，覆蓋攻擊力顏色；敵方子彈的紅色與橘色的專屬意義不變
