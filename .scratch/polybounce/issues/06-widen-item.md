# 06：加寬道具

**要建置什麼：** 新增第二種道具：加寬。接到的玩家擋板變寬一段時間，時間到恢復原本寬度。這是個人道具，只影響接到的那位玩家，同批道具各自接各自的。同種效果再次接到時只重新計時，不疊加。

**Blocked by（被誰阻擋）：** 05：道具掉落與補給

**Status：** ready-for-agent

- [ ] 道具的掉落類型包含加寬，同一批掉落的所有道具仍然是同一種類型
- [ ] 接到加寬的玩家擋板變寬，其他玩家的擋板不受影響
- [ ] 效果持續時間寫成可調整的常數，預設 10 秒，時間到擋板恢復原寬度
- [ ] 效果期間再接到加寬，只重新計時，寬度不再增加
- [ ] 同一批的加寬道具，每位玩家各自接各自的，不會因為別人接到而消失
- [ ] 擋板變寬後，接球與反彈角度的計算仍然正確
- [ ] 遊戲核心的新行為都有測試，現有測試維持通過
- [ ] 畫面上能看到擋板寬度的變化，並在真實瀏覽器確認過
