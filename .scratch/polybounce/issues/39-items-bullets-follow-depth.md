# 39：道具與敵方子彈跟著深度

**要建置什麼：** 擋板可以內外移動之後，其餘會互動的東西也要和深度一致：道具在擋板目前的位置被接到，沒接到的仍飛到原本的邊緣才消失；怪物與 BOSS 瞄準的是玩家核心的實際位置，子彈打到的也是核心的實際位置，越過有玩家那一邊才消失的線仍在原本的邊緣；屍體停在死亡時的深度，死亡方位的牆仍在邊緣，復活進度仍在彈珠撞到該方位屍體沿邊範圍的牆時累計。相鄰兩邊的擋板在角落重疊時不影響判定。來源：規格 0004。

**Blocked by（被誰阻擋）：** 38：擋板可往內移動

**Status：** ready-for-agent

- [ ] 道具在擋板目前的深度範圍內才被接到；擋板往內迎接能更早接到
- [ ] 沒接到的道具飛到原本的邊緣才消失，不受擋板深度影響
- [ ] 怪物與 BOSS 的瞄準目標、一般怪物的子彈，以及 BOSS 彈幕中瞄準玩家的扇形，都對準目標玩家核心的實際位置
- [ ] 子彈只有碰到核心的實際位置才扣血；擋板其他部分仍穿過；無敵期間仍穿過
- [ ] 子彈越過有玩家的那一邊才消失，位置不隨擋板深度改變
- [ ] 死亡玩家的屍體畫在死亡時的深度，該方位的牆仍在邊緣；彈珠撞到該方位屍體沿邊範圍的牆時累計復活進度，累計五次復活
- [ ] 相鄰兩邊的擋板在角落重疊時，各自的碰撞、核心與道具拾取不互相影響
- [ ] 測試涵蓋：道具在目前深度被接到與在邊緣消失、瞄準目標是核心實際位置、子彈判定隨核心位置、越界線不變、屍體深度與邊緣牆的復活累計、角落重疊不影響判定
- [ ] 手動驗證：屍體漂在離牆最多一百像素處的視覺是否可以接受只能在瀏覽器中目視確認，不屬於自動化測試範圍；若不順，改成死亡時把屍體貼回邊緣
