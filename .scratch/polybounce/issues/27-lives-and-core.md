# 27：生命與核心受擊

**要建置什麼：** 每位玩家有獨立的生命，初始 3 點。擋板中央有一個 16×16 的核心方塊，位置隨擋板移動、大小不隨擋板寬度改變，只與子彈碰撞，不影響彈珠。子彈穿過擋板本身，只有打到核心才使該玩家扣 1 點生命並消失，受傷後有 1.5 秒無敵，期間子彈穿過核心。凍結與 BOSS 無敵機制整個移除。過關時所有玩家生命補滿。畫面上每位玩家在自己那一邊顯示生命圓點，核心用玩家顏色並在無敵時閃爍，受傷有音效。生命歸零後的死亡行為由下一張票券處理，這裡先維持 0 點生命。來源：規格 0003。
