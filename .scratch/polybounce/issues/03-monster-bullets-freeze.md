# 03：怪物發射子彈與凍結

**要建置什麼：** 怪物每 5 秒向隨機一位仍在場上的玩家發射一發子彈。子彈打到磚塊或牆會消失；打到擋板會讓該玩家凍結 1 秒，凍結期間再被擊中，凍結時間重新計為 1 秒。凍結只鎖擋板移動，瞄準與發射不受影響。畫面要畫出子彈與凍結狀態，讓玩家看得出自己被凍結了多久。

**Blocked by（被誰阻擋）：** 02：怪物出現並能被打倒

**Status：** ready-for-agent

- [ ] 怪物存在時，每隔 5 秒發射一發子彈，沒有怪物就不發射
- [ ] 子彈射向隨機一位仍在場上的玩家，已經離開的方位不會成為目標
- [ ] 子彈打到磚塊或牆就消失，不會無限累積
- [ ] 子彈打到擋板使該玩家凍結 1 秒，只有碰到擋板才算，沒碰到不算
- [ ] 凍結期間擋板不能移動，但仍然可以進入瞄準模式與發射彈珠
- [ ] 凍結期間再被擊中，凍結時間重新計時，不延長也不設免疫期
- [ ] 凍結不影響其他玩家
- [ ] 遊戲核心的新行為都有測試，現有測試維持通過
- [ ] 畫面上能看到子彈與凍結，並在真實瀏覽器確認過
