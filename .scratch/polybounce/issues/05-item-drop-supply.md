# 05：道具掉落與補給

**要建置什麼：** 擊碎磚塊時有 15% 機率掉落道具。每次掉落朝每位玩家的方位各掉一個，類型相同，緩慢飄向該方位。玩家用擋板碰到才拾取，沒接到就消失。先實作第一種道具：補給，讓彈珠池增加 5 顆，有上限，同一批只有第一個被接到的生效，其餘同批的道具立刻消失。

**Blocked by（被誰阻擋）：** 01：預先重構

**Status：** ready-for-agent

- [ ] 擊碎磚塊有機會掉落道具，機率寫成可調整的常數，預設 15%
- [ ] 每次掉落，每一位在場的玩家方位都各有一個同類型的道具；沒有玩家的牆不會有道具
- [ ] 道具緩慢飄向對應的方位，被該方位的擋板碰到才拾取
- [ ] 沒有被接到的道具在離開場地後消失，不影響彈珠池
- [ ] 補給被接到時彈珠池增加 5 顆，且不超過人數乘以 20 的上限
- [ ] 同一批補給只有第一個被接到的生效，其餘立刻消失
- [ ] 遊戲核心的新行為都有測試，隨機掉落可以用固定種子或注入來測試
- [ ] 畫面上能看到道具與補給效果，並在真實瀏覽器確認過
