# 29：屍體復活

**要建置什麼：** 彈珠撞到屍體區域時，照牆的方式反彈，同時為該屍體累計一次復活進度。累計 5 次，死亡的玩家復活：生命 1 點、無敵 1.5 秒、進度歸零，擋板恢復可操作，方位恢復為有玩家的狀態。撞到牆的其他位置不累計。屍體上顯示復活進度，復活時有音效。環爆一次分出多顆彈珠時，一瞬間累計到 5 次可以直接復活。來源：規格 0003。

**Blocked by（被誰阻擋）：** 28：死亡與屍體

**Status：** ready-for-agent

- [ ] 彈珠每次反彈到屍體區域，該屍體的復活進度加 1；撞到牆的其他部分不累計
- [ ] 累計到 5 次，玩家復活：生命 1 點、無敵 1.5 秒、復活進度歸零，可以重新移動、瞄準與發射
- [ ] 復活後方位恢復為有玩家的狀態，彈珠漏接判定、道具掉落與怪物鎖定恢復
- [ ] 環爆等造成同時多次撞擊的情況，累計次數正確，可以一次就復活
- [ ] 屍體上顯示復活進度，並新增復活音效
- [ ] 連線：玩家端收到的復活進度與房主一致
- [ ] 測試涵蓋：累計次數、第 5 次復活、復活後的狀態、撞非屍體區域不累計、過關復活仍有效
- [ ] 詞彙表新增「復活」；README 補上復活說明
