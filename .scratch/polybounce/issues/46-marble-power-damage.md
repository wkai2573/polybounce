# 46：攻擊力累積與扣血

**要建置什麼：** 每顆彈珠有攻擊力，初始為一，被任何玩家的擋板彈回一次就加一。磚塊、怪物與 BOSS 被打到扣的血量等於彈珠的攻擊力，貫通期間每次進入扣的也是攻擊力。多球與環爆分出的新彈珠從攻擊力一開始。這張票券完成時彈珠的外觀還沒有變化，由後面的票券補上。這裡的子彈指彈珠，不是怪物的子彈。來源：規格 0005。

**Blocked by（被誰阻擋）：** 無（可立即開始）

**Status：** 待手動驗證

- [x] 每顆彈珠有攻擊力欄位，新發射時為一，隨彈珠狀態同步到連線的玩家端
- [x] 擋板實際反彈的那一下攻擊力加一；任何活著玩家的擋板都算，不限於發射它的人
- [x] 撞牆、磚塊、怪物、屍體所在的牆不增加攻擊力；沒有上限
- [x] 多球分裂與環爆分出的新彈珠攻擊力為一，不繼承原彈珠
- [x] 磚塊被打到扣的血量等於攻擊力，扣到零以下仍正常碎裂、得分與掉落；得分仍以最大血量計，不看攻擊力
- [x] 怪物與 BOSS 被打到扣的血量等於攻擊力；血量一次降過多個掉落門檻時，仍只掉落一次道具
- [x] 貫通期間，彈珠每進入一塊磚或一隻怪物扣的血量等於攻擊力
- [x] 磚塊與怪物的血量、得分公式不變
- [x] 詞彙表新增「攻擊力」，更新「彈珠」「貫通」；README 同步
