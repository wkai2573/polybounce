# 15：環爆道具

**要建置什麼：** 新增稀有的「環爆」道具。玩家接到時，場上每顆彈珠原地分裂成 10 顆，以 36 度間隔向四周散開，速度大小不變。環爆是全隊共用的效果，場上彈珠數量仍有 100 顆的上限。道具的顏色與標籤和其他道具不同，並且比其他道具稍醒目。來源：規格 0002。

**Blocked by（被誰阻擋）：** 13：掉落率與權重制；14：貫通道具

**Status：** done

- [x] 環爆加入道具種類，權重為 5
- [x] 接到環爆時，場上每顆彈珠分裂成 10 顆（原本那顆加上新增的 9 顆），方向間隔 36 度，速度大小與原彈珠相同
- [x] 分裂後場上彈珠總數不超過上限 100，超過的不產生
- [x] 場上沒有彈珠時接到環爆沒有任何效果，也不影響彈珠池
- [x] 分裂出的彈珠繼承原彈珠的貫通剩餘時間
- [x] 同一批環爆只有第一個被接到的生效
- [x] 環爆道具的顏色與標籤獨特且稍醒目；拾取音效沿用現有的道具拾取音效
- [x] 詞彙表新增「環爆」，道具清單同步更新
- [x] 遊戲核心的新行為都有測試，現有測試維持通過
