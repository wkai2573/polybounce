# 10：PeerJS 房間：建立、加入與開局

**要建置什麼：** 用 PeerJS 實作真實的傳輸，讓玩家能開房間一起玩。房主建立房間並得到房間碼，其他人輸入房間碼加入。大廳顯示「玩家 1 到 4」與各自的顏色，方位依加入順序分配（下、上、左、右），房主按下開始後進入遊戲，開局後不能再中途加入。

**Blocked by（被誰阻擋）：** 09：傳輸層與房主權威

**Status：** done

- [x] 房主能建立房間並看到房間碼；其他玩家輸入房間碼就能加入
- [x] 房間最多 4 人，第 5 位嘗試加入會被拒絕並看到說明
- [x] 大廳顯示每位玩家的編號、方位與顏色，加入或離開時即時更新
- [x] 方位依加入順序分配為下、上、左、右
- [x] 房主按下開始後，所有人進入同一局遊戲，彈珠池為人數乘以 10
- [x] 開局後不能中途加入
- [x] 其他玩家的滑鼠輸入透過連線送到房主，擋板與發射在房主端生效，畫面在各玩家端同步
- [x] 連線細節（房間碼格式、連線錯誤訊息）可以在真實瀏覽器用兩個分頁驗證
- [x] 新增的測試只針對可以不依賴真實 PeerJS 測試的部分
