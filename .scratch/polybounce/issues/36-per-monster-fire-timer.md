# 36：怪物各自計時，間隔隨關卡縮短

**要建置什麼：** 每隻一般怪物有自己的發射倒數，歸零時向隨機一位活著的玩家射一發。發射間隔從第三關起為三秒，之後每過五關縮短半秒，最短一點五秒。每隻怪物的初始倒數在一個間隔內均勻錯開，避免開局齊射。倒數隨狀態同步。BOSS 彈幕與場上子彈總數上限不變。來源：規格 0004。

**Blocked by（被誰阻擋）：** 35：多隻怪物

**Status：** ready-for-agent

- [ ] 每隻一般怪物各自倒數、各自挑選目標，目標只會是活著的玩家
- [ ] 發射間隔：第三關到第七關三秒，之後每過五關減半秒，第十八關起固定一點五秒
- [ ] 同一關多隻怪物的初始倒數互相錯開，開局不會在同一瞬間全部發射
- [ ] 場上子彈總數達到上限時，所有怪物暫時不再發射，BOSS 彈幕規則不變
- [ ] 怪物的發射倒數包含在同步的狀態裡，玩家端與房主一致，且經過數字壓縮後行為不變
- [ ] 測試涵蓋：各關卡的間隔、下限、各自計時、初始倒數錯開、目標只選活著的玩家、達到上限不發射、玩家端收到的倒數與房主一致，並改寫假設全場共用一個發射倒數的既有測試
- [ ] 手動驗證：實際玩起來的子彈密度與手感只能在瀏覽器中目視確認，並依手感調整間隔常數
