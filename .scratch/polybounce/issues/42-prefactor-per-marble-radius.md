# 42：預先重構，半徑改為每顆彈珠各自計算

**要建置什麼：** 牆、擋板、磚塊、怪物的碰撞、漏接判定與切段移動的步長，從使用全場共用的半徑，改為讀取每顆彈珠自己的半徑。目前所有彈珠的半徑仍然相同，由現有的整場大小效果決定，所以遊戲行為完全不變。這是攻擊力改變半徑的前置。來源：規格 0005。

**Blocked by（被誰阻擋）：** 無（可立即開始）

**Status：** ready-for-agent

- [ ] 取得半徑的方式改為「給定一顆彈珠，回傳它的半徑」，所有使用半徑的地方都傳入彈珠
- [ ] 新發射彈珠的起點使用基礎半徑
- [ ] 既有的所有測試不改預期值，全部通過
- [ ] 新增測試：在場上同時放兩顆半徑不同的彈珠時，各自用自己的半徑碰撞與判定漏接，其中一顆不會被另一顆的半徑影響；測試可用受測接縫提供的方式放置，不新增公開欄位
- [ ] 型別檢查與測試全綠
- [ ] 手動驗證：遊玩時彈珠大小、放大與縮小道具的效果與改動前完全相同
