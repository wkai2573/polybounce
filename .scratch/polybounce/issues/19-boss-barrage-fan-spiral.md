# 19：BOSS 彈幕：瞄準扇形與螺旋

**要建置什麼：** BOSS 在環形之外，再加入兩種彈幕並輪流施放：瞄準扇形（朝隨機一位玩家射出 7 發，夾角約 40 度）和螺旋（連續射出約 2 秒，每 0.1 秒一發，角度逐漸旋轉）。三種樣式依序輪替，狂暴時三種都加強，同樣受場上子彈上限約束。來源：規格 0002。

**Blocked by（被誰阻擋）：** 18：BOSS 彈幕：環形、狂暴與子彈上限

**Status：** needs-manual-verification

- [x] BOSS 依序輪替環形、瞄準扇形、螺旋三種樣式
- [x] 瞄準扇形朝隨機一位仍在場上的玩家，7 發、夾角約 40 度，中央那發對準該玩家的擋板
- [x] 螺旋約持續 2 秒，每 0.1 秒射出一發，發射角度逐次旋轉
- [x] 狂暴時三種樣式的發數增加、間隔縮短，數值寫成可調整的常數
- [x] 三種樣式的子彈同樣是 BOSS 的子彈：半徑、顏色、凍結規則與環形一致，並受場上子彈上限約束
- [x] 玩家離開使場上沒有玩家時，不會因為挑選目標而出錯
- [ ] 手動試玩一次完整的 BOSS 關，確認三種彈幕都有縫隙可閃，必要時調整夾角與間隔；實測結果寫進票券備註
- [x] 遊戲核心的新行為都有測試，現有測試維持通過
