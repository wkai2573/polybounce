# 20：起始關卡：單人選關與再來一局回起點

**要建置什麼：** 遊戲可以從任意關卡開始。遊戲核心接受起始關卡的選項，並在狀態中記錄這一局的起點。單人玩家在主選單選擇起始關卡（1 到 99），彈珠池、磚塊、怪物與彈珠速度都依該關卡計算。「再來一局」改為回到這一局的起始關卡，而不是一律回第 1 關。來源：規格 0002。

**Blocked by（被誰阻擋）：** 無（可立即開始）

**Status：** done

- [x] 遊戲核心接受起始關卡選項，預設為第 1 關；起始關卡之前的關卡不會被生成
- [x] 從第 N 關開始時，磚塊與怪物配置、彈珠速度、是否為 BOSS 關都和一路打到第 N 關時一致
- [x] 彈珠池依玩家人數補滿，場上沒有彈珠，分數從 0 開始
- [x] 遊戲狀態記錄這一局的起始關卡，並包含在同步給連線玩家端的狀態中
- [x] 主選單提供起始關卡的輸入（1 到 99，預設 1），輸入超出範圍時被限制在範圍內
- [x] 單人的「開始」使用所選的起始關卡
- [x] 「再來一局」回到這一局的起始關卡，並換新 seed；起始關卡為 1 時行為和現在一致
- [x] 詞彙表新增「起始關卡」，更新「局」的說明
- [x] 遊戲核心與房主會話的新行為都有測試，現有測試維持通過
