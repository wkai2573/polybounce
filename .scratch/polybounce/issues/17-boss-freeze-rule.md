# 17：BOSS 子彈的凍結規則

**要建置什麼：** BOSS 的子彈改用專屬的凍結規則，讓之後的彈幕不會把玩家永久鎖死：打到擋板凍結 0.5 秒；已經被凍結時再被打到，不重新計時，子彈直接消失；解凍後有 1 秒無敵，期間 BOSS 的子彈穿過擋板、不凍結也不消失。一般怪物的子彈維持現有規則：凍結 1 秒，凍結中再被打到重新計時。來源：規格 0002。

**Blocked by（被誰阻擋）：** 16：所有怪物的子彈穿過磚塊

**Status：** ready-for-agent

- [ ] BOSS 的子彈打到未凍結且無敵已結束的擋板時，該玩家凍結 0.5 秒，子彈消失
- [ ] 凍結期間再被 BOSS 的子彈打到，凍結剩餘時間不變，子彈消失
- [ ] 解凍後 1 秒內為無敵：BOSS 的子彈穿過擋板，不凍結、不消失
- [ ] 無敵剩餘時間是每位玩家的狀態，隨狀態同步到連線玩家端
- [ ] 一般怪物的子彈完全維持舊規則：凍結 1 秒，凍結中再被打到重新計時，不受 BOSS 的無敵影響
- [ ] 凍結與解凍的音效事件仍然正確（凍結音效只在新凍結時觸發）
- [ ] 詞彙表更新「凍結」的說明，並新增 BOSS 子彈的無敵
- [ ] 遊戲核心的新行為都有測試，現有測試維持通過
