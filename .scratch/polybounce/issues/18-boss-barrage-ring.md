# 18：BOSS 彈幕：環形、狂暴與子彈上限

**要建置什麼：** BOSS 不再每 5 秒射一發，改成每約 1.2 秒施放一次環形彈幕：以 BOSS 為中心射出一圈 24 發，每次齊射轉動一點角度，讓縫隙每次不同。BOSS 血量降到一半以下進入狂暴，間隔縮短、數量增加。BOSS 的子彈比一般子彈小、顏色不同，速度在 160 到 240 之間。場上子彈總數有上限，達到上限時暫時不再發射。一般怪物維持每 5 秒一發。來源：規格 0002。

**Blocked by（被誰阻擋）：** 16：所有怪物的子彈穿過磚塊；17：BOSS 子彈的凍結規則

**Status：** done

- [x] BOSS 約每 1.2 秒施放一次環形彈幕，一圈 24 發，均勻分佈在 360 度，每次齊射整體轉動一點角度
- [x] BOSS 血量降到一半以下進入狂暴：齊射間隔縮短、每圈發數增加，數值寫成可調整的常數
- [x] BOSS 子彈的速度在 160 到 240 之間，碰撞半徑為 4，一般怪物的子彈維持半徑 5
- [x] BOSS 子彈在畫面上與一般子彈顏色不同、一眼分得出來
- [x] 場上子彈總數上限（目前 100 發，實測連線吃緊後由 150 調低），達到上限時暫時不再發射，之後數量下降會恢復
- [x] 一般怪物維持每 5 秒向一位玩家發射一發，不受 BOSS 彈幕影響
- [x] 彈幕不影響彈珠的物理
- [x] 手動在連線房間試玩 BOSS 關，確認其他玩家端的子彈看起來流暢，必要時調低上限；實測結果寫進票券備註
- [x] 詞彙表新增「彈幕」，更新「BOSS」的說明
- [x] 遊戲核心的新行為都有測試，現有測試維持通過
