# 50：旋轉視角

**要建置什麼：** 每位玩家的畫面都旋轉成自己的方位在下方，房主與玩家端一樣。滑鼠左右移動時擋板沿畫面左右移動，上下移動時沿畫面上下移動，操作與畫面一致。旋轉是真的旋轉不是鏡像，方位順序和房間裡所有人一致。文字、生命點與效果面板維持正向。這是純畫面層的改動，遊戲核心與連線同步都不變。來源：規格 0005。

**Blocked by（被誰阻擋）：** 無（可立即開始）

**Status：** ready-for-agent

- [ ] 新增純函式，依本機玩家的方位，在場地座標與畫面座標之間互相轉換，涵蓋點與位移兩種；下方玩家為恆等，上方玩家轉一百八十度，左右玩家各轉九十度，永遠是旋轉不是鏡像
- [ ] 場地的繪製依本機方位整個旋轉，自己的擋板永遠在畫面下方；文字、生命點、鎖定提示維持正向，不跟著旋轉
- [ ] 滑鼠座標先由畫面座標轉成場地座標，再交給遊戲核心；指標鎖定模式下的位移也同樣轉換，鎖定與未鎖定的手感一致
- [ ] 遊戲開始與接關時，指標從自己那一邊的邊緣開始，畫面上永遠是下緣
- [ ] 死亡後視角維持原方位不翻轉；單人玩家的畫面與以前完全相同
- [ ] 房主與玩家端各自旋轉，不增加任何同步資料，連線資料量不變
- [ ] 詞彙表新增「視角」；README 補上旋轉視角的說明
- [ ] 測試涵蓋：四個方位的點與位移轉換正確、轉換與反轉換互為反函數、下方玩家為恆等、旋轉不是鏡像
- [ ] 手動驗證：四個方位的玩家都看到自己在下方，滑鼠左右上下移動與擋板移動方向一致，指標鎖定時也一致；文字沒有被轉倒；房主與玩家端各自正確；死亡時畫面不翻轉。旋轉繪製與指標鎖定手感只能在瀏覽器中目視確認，不屬於自動化測試範圍
