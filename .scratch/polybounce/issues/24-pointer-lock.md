# 24：滑鼠鎖定與 Esc 暫停

**要建置什麼：** 對局進行中，點擊畫面就鎖定滑鼠，滑鼠不會再移出視窗。準星改由鎖定後累積的虛擬指標驅動，並限制在場地內。按 Esc 會解除鎖定：房主與單人同時視為暫停，再點一下畫面就重新鎖定並繼續；這一下重新鎖定的點擊不算遊戲輸入，不會誤觸瞄準或發射。主選單、大廳、暫停與結算畫面不鎖定。來源：規格 0002。

**Blocked by（被誰阻擋）：** 23：準星

**Status：** ready-for-agent

- [ ] 對局進行中點擊畫面進入滑鼠鎖定；鎖定期間滑鼠不會離開視窗，準星與擋板依累積的位移移動，位置限制在場地 0 到 800 內
- [ ] 重新進入鎖定的那一下點擊只用來鎖定，不傳給遊戲當作瞄準或發射
- [ ] 鎖定被解除（Esc 或失去焦點）時，房主與單人進入暫停，畫面提示再點一下繼續；再點一下即重新鎖定並繼續
- [ ] 非房主的玩家解除鎖定時不會暫停遊戲，畫面提示再點一下重新鎖定
- [ ] 房主暫停時，非房主的玩家畫面仍然顯示「房主已暫停」，不受鎖定狀態影響
- [ ] 主選單、大廳、暫停與結算畫面不鎖定，使用一般的系統游標與按鈕
- [ ] 失敗或回到主選單時自動解除鎖定
- [ ] 瀏覽器不支援或拒絕鎖定時，退回原本的行為，遊戲仍可玩
- [ ] README 的操作說明補上滑鼠鎖定與 Esc 的行為
- [ ] 手動驗證：單人與連線房間、Esc、切換分頁、重新鎖定的行為；Pointer Lock 不屬於自動化測試範圍
