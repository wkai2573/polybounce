# 13：掉落率與權重制

**要建置什麼：** 磚塊被擊碎時的道具掉落率提高到 25%，並且道具種類改成權重制抽選，不再是三種各佔三分之一。磚塊掉落與怪物血量門檻的必掉共用同一份權重。這張票券先對現有的補給、加寬、多球生效，權重為多球 30、補給 25、加寬 25，多球因此最常出現。之後新增的道具只需要把自己的權重加進去。來源：規格 0002。

**Blocked by（被誰阻擋）：** 無（可立即開始）

**Status：** done

- [x] 磚塊掉落率預設為 25%，仍可由遊戲選項覆寫
- [x] 掉落的道具種類依權重抽選，權重與掉落率都寫成可調整的常數
- [x] 怪物血量門檻的必掉使用同一份權重
- [x] 以固定種子大量抽選時，各種道具的比例落在權重預期的合理範圍內，測試不要求精確值
- [x] 遊戲選項可以限定可掉落的道具種類（現有測試用法）時，仍然只在限定的種類中抽選
- [x] 現有的道具與掉落測試維持通過
